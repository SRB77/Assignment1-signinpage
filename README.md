# Osler Telehealth Sign-In UI

This project contains a pixel-perfect, completely responsive React Native implementation of a green-themed Telehealth Sign-In screen.

## Features
- Built with React Native & Expo
- Uses ONLY core React Native components (no external UI libraries)
- Custom-built programmatic Logo
- Responsive `KeyboardAvoidingView` layout
- Bug-free focus state management without layout shifts
- Beautiful modern PNG icon assets
